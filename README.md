# Analisis Sentimen Pengguna Aplikasi Blibli
Algoritma Multinomial Naive Bayes + TF-IDF kata dan karakter. Aplikasi Streamlit untuk memproses komentar baru.

Menu: Beranda, Analisis Komentar, Preprocessing, Riwayat & Excel, Visualisasi, Evaluasi Algoritma.

File: `app.py`, `model_naive_bayes_blibli_final.pkl`, `hasil_penelitian.json`, `requirements.txt`.
Jalankan lokal: `pip install -r requirements.txt` lalu `streamlit run app.py`.
